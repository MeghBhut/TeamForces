    Create a contest

    Enter one rating per problem (comma-separated). The server picks a random problem for each rating, skipping anything any member has already solved. You won't see the chosen problems until you start it.

    Leave the schedule empty to start it yourself with a button. Set a time and it opens automatically then.

    Register a person

    Create the account, then email the person their username & password. Their CF handle lets the poller track their solves.

    Problemset cache
